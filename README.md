# Acompanhamento de Testes e Pesquisas

Aplicação local para organizar estudos, testes, pesquisas e sessões com participantes.

## Desenvolvimento

```powershell
npm install
npm run dev
```

## Persistência

Os registros ficam no `localStorage` deste navegador e deste dispositivo. Não há servidor, sincronização ou envio de dados para uma API.
